# Get started

```sh
npm install @msb235/blinken
```

blinken needs a canvas and nothing else: no framework, no three.js, no fonts or images to load. It brings [blits](https://michaelbaker.tech/blits/) with it, which mixes the effects.

## A sign

`createMarquee` puts a sign on a canvas and plays a program on it: a list of scenes, each a message, its color, and the effect it plays. The program loops.

<Live client:only="react" of="start.ts" />

<Listing of="live/start.ts" />

The canvas takes the largest size its parent element allows, keeping the sign's shape, so give the parent a size. (`stage` and `held` belong to this site: `stage` makes a canvas in a box shaped like the sign, and `held` pauses it with the demo's Pause button.)
