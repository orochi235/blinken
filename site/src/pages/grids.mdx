# Grids

`grid` sets how the dots are laid out. Text and effects still count dots by column and row, whatever the grid; only the drawing changes.

<Live client:only="react" of="grids.ts" />

<Listing of="live/grids.ts" />

| Grid | Layout |
|---|---|
| `square` | The default. |
| `hex` | Each row sits half a dot left of the one above, rows √3/2 apart, so every dot has six neighbors a pitch away. The columns run on a slant, so text leans like italics. |
| `triangles` | Regular hexagons each cut into six: rows of triangles pointing up and down in turn, each its own light. A letter's dot lights the two triangles at its place, so the sign is twice as many across: 160 by default. The `strokes` face draws a triangle to a dot instead, on 14 rows or more. |

A function `(x, y) => [x, y]` places the dots a grid of your own way, in pitches, and the sign is fitted to wherever they land.
